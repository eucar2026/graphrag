# QueryPDF.ai

## How to start the server

The server side is written with Python, LlamaIndex, Postgres, and PGVector. 

- Development: fastapi dev main.py

- Production: fastapi run main.py

## How to start client side

The client side is an SPA (single-page application) written with React for the system user interface. 

- Development: pnpm run dev

- Build: pnpm run build

- Production: pnpm start
